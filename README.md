## 📖 Overview

**Data Reseller Platform** is a full-stack system for managing and selling mobile data bundles.  
It allows customers to browse MTN bundles, place orders, pay, and receive SMS notifications for delivery.  
Admins manage bundles, prices, and transactions via a secure dashboard.
